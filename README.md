The code of [mikraot.net](https://mikraot.net), a Hebrew site for learning to read the Bible:
pronunciation, grammar and cantillation, with recorded readings.

Astro (static pages) with small Preact islands, TypeScript and Tailwind, served by one Cloudflare
Worker with a D1 database. The site is moving here from WordPress.
