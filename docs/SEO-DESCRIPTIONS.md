# Search-engine descriptions: proposal for Arye

Each page has a description that Google may show under its title in search results. The current
ones are WordPress's automatic excerpts: 177 to 564 characters (Google shows about 155) and mostly
cut off mid-sentence. Below, a short description per page, written from its own opening text
(each under 155 characters), in the form "title: description" (Arye, 2026-10-08).
**Nothing changes on the site until Arye approves**; then they go into each
page's `seo.description` (editable later in Keystatic, page settings).

Measured 2026-10-08: 34 published pages, 33 descriptions too long or cut off.
