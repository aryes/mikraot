# Taamey D

Font for biblical text with cantillation marks, by Ben Denckla, derived from Taamey Frank CLM
(Culmus project). Release v0.921-2, unaltered:
https://github.com/bdenckla/Taamey_D/releases/tag/v0.921-2

Licence: GNU GPL v2 with the font embedding exception (`license.txt`).

`Taamey_D-logo.woff2`, the file the site loads, is a modified version: trimmed to the letters of
the site's name by `scripts/fonts/subsets.py` (2026-10-20). `Taamey_D.woff2` is the original.
