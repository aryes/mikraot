# Taamey David CLM (modified)

The site's font since 2026-10-14: Taamey David CLM by Yoram Gnat, from the Culmus project
(<https://culmus.sourceforge.net/taamim/>), version of 2010.

These files are **modified** versions, made by `scripts/fonts/taamey-david.py` from the unaltered
originals in `scripts/fonts/taamey-david/` (the corresponding source):

- both weights enlarged 7% (a smaller units-per-em), to match the letter size of the site's
  earlier font;
- the bold rebuilt from the medium weight with the bold's letters, because the original bold
  has no cantillation marks.

The fonts' version string records the change. Licence: GNU GPL v2 (`GNU-GPL`) with the font
embedding exception (`LICENSE`), which these modified versions keep.
