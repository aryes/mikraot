# Noto Hebrew with bold marks

Modified copies of the Hebrew subsets of Noto Sans Hebrew and Noto Serif Hebrew (variable fonts,
from the Fontsource packages `@fontsource-variable/noto-sans-hebrew` and
`@fontsource-variable/noto-serif-hebrew`; versions in `versions.json`). The only change: every
vowel and cantillation mark has the outline of the weight-800 instance at all weights, so marks
stay bold next to regular letters. Made by `scripts/fonts/bold-marks.py`.
