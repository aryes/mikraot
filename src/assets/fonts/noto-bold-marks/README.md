# Noto Sans Hebrew with bold marks

A modified copy of the Hebrew subset of Noto Sans Hebrew (variable font, from the Fontsource
package `@fontsource-variable/noto-sans-hebrew`; version in `versions.json`). The only change:
every vowel and cantillation mark has the outline of the weight-800 instance at all weights, so
marks stay bold next to regular letters. Made by `scripts/fonts/bold-marks.py`.

Licence: SIL Open Font License 1.1, unchanged (`OFL-noto-sans-hebrew.txt`). Noto has no Reserved
Font Name, so the copy keeps the name.
